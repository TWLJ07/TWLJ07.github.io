# Tucker Johnson - portfolio

Single-page static portfolio for GitHub Pages. Open index.html or serve this directory with any static HTTP server. No build is required. Manrope and Space Grotesk are loaded from Google Fonts with system-font fallbacks and swap rendering.

- index.html: about, drone flight-path projects, experience, PDF downloads, contact, and static project galleries.
- styles.css: responsive layout, drone illustration animation, reduced-motion support.
- script.js: scroll position, accessible native image dialog, section navigation.
- projects.html and work.html: redirects for old links.
- portfolio.html: redirects the old HTML portfolio address to the supplied portfolio PDF.

Project images live under assets/projects in Drone Software, Marine Buoy, Test Fixtures, and Navbot. Main images are Dense_Points.png, BUOY_1.png, SD_TOP.jpg, and Robot1.png respectively. The remaining images appear in each project's expandable gallery. Image buttons open the original files in a modal viewer.

The download links use assets/projects/Resume/Tucker_Johnson_Resume.pdf and assets/projects/Portfolio/Tucker_Johnson_Project_Portfolio.pdf.

The drone illustration is an original inline SVG, not a model of a completed project. Project descriptions use the supplied portfolio information.
